# Security policy

## Supported versions

Security fixes are provided for the latest published stable release of Far Far VR. Update to the latest release before reporting an issue when practical. Older releases may not receive separate fixes.

## Report a vulnerability privately

Use **Security > Report a vulnerability** on this repository:

https://github.com/pr-io/Far-Far-VR/security/advisories/new

Please keep security-sensitive details out of public issues, discussions and Discord while a report is being assessed and a fix is being prepared.

Include:

- The affected Far Far VR version and Windows version.
- A description of the vulnerability and its potential impact.
- Reproduction steps or a minimal proof of concept.
- Relevant logs with credentials, tokens, personal information and unrelated data removed.

Useful reports include problems with launcher downloads, update validation, file handling, runtime installation, or repository automation. For vulnerabilities in upstream UEVR, Steam, the game, or a headset runtime, use that project's security reporting process; mention any Far Far VR-specific interaction in your report here.

Maintainers will assess reports and coordinate fixes and disclosure through the private report. Response times depend on maintainer availability.

## Ordinary bugs and support

Use [GitHub Issues](https://github.com/pr-io/Far-Far-VR/issues) for ordinary gameplay bugs, headset compatibility problems, feature requests and installation support that do not expose a security vulnerability.
